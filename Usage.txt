Useful commands

Start central services: "./br.sh" run from root directory - make sure to run chmod +x ./br.sh 


"./start.sh can be run from the cp directory - make sure to run the first time chmod +x ./start.sh
It must be run giving the parameters required to start a Charger

eg:

./start.sh set1212 "-ci 192.168.100.100 -cp 5500 -ei 192.168.100.30 -ep 5050 -l alicante -u 12345 -r"
